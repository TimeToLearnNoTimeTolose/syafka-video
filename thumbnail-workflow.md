# Thumbnail Workflow

## YouTube

Timeline:

- 1280 x 720

Workflow:

1. Grab Still from Resolve
2. Build thumbnail using multiple PNG layers
3. Adjust:
   - Opacity
   - Colour
   - Position
4. Export PNG
5. Upload in YouTube Studio
