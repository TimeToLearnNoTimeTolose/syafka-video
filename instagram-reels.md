# Instagram Reels

## Timeline

* Create a new timeline in the `Timelines` folder.
* Resolution: 1080 x 1920.
* Frame Rate: 30fps.

## Workflow

1. Import the final Resolve export video.
2. Drag the video onto the Instagram timeline.
3. Select the strongest 30–60 second section.
4. Cut the clip to the required length.
5. Reframe the video for the vertical 9:16 timeline if required.
6. Keep important visual elements and text inside the safe area.

## Fades

* Add a 1 second fade at the start.
* Add a 1 second fade at the end.
* Use `Cross Dissolve` from:
  `Effects → Video Transitions`
* Apply the transition to the beginning and end of the video.
* Fade the audio over the same duration.

## Title

- Add `Long Title Lower Third` on a video track above the footage.
- First line: `SYAFKA |`
- Second line: current track title in capitals.
- Font: Open Sans
- Weight: Bold
- Colour: White
- Size: 0.0591
- Tracking: 1.165
- Line Spacing: 1.0
- Keep text left-aligned.
- Position the title below the centre of the vertical frame, as in the reference layout.
- Adjust size or line breaks for longer track titles.
- Check readability on a phone-sized display.
- Keep text away from the extreme top, bottom and right-hand edges so platform controls do not cover it.
- Check that the imported video does not already contain a visible title before adding another.

## Export

Use the saved `Insta_Export` preset.

Current preset:

* Format: MP4
* Codec: H.264
* Resolution: Timeline Resolution (1080 x 1920)
* Frame Rate: Timeline Frame Rate (30fps)
* Hardware Acceleration: Enabled
* Quality: Automatic
* Encoding Profile: Auto
* Key Frames: Automatic
* Frame Reordering: Enabled
