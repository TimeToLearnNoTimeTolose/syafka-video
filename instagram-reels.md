# Instagram Reels

## Timeline

* Create a new timeline in the `Timelines` folder.
* Resolution: 1080 x 1920.
* Frame Rate: 30fps.

## Workflow

1. Import the final Resolve export video.
2. Drag the video onto the Instagram timeline.
3. Select the strongest 30–60 second section.
4. Cut the clip to the required length.
5. Reframe the video for the vertical 9:16 timeline if required.
6. Keep important visual elements and text inside the safe area.

## Fades

* Add a 1 second fade at the start.
* Add a 1 second fade at the end.
* Use `Cross Dissolve` from:
  `Effects → Video Transitions`
* Apply the transition to the beginning and end of the video.
* Fade the audio over the same duration.

## Title

1. Copy the `Long Title Lower Third` clip from the previous Reel onto a video track above the footage. This keeps the same styling and position each time.
2. Select the title clip and open `Inspector → Title → Controls`.
3. Keep `SYAFKA |` on the first line. Replace the second line with the current track title in capitals.

   Example:

       SYAFKA |
       UNTIL WE ARE DUST

4. Preview at phone size. If a longer title runs too close to the right edge, split the track name across two lines. Reduce the size only if needed.

### Reference settings

- Font: Open Sans, Bold
- Colour: White
- Size: 0.0866
- Tracking: 1.165
- Line spacing: 1.0
- Vertical anchor: Top (-1.0)
- Horizontal anchor: Left (-1.0)
- Placement: Below the centre of the vertical frame, matching the previous Reel

If the exported footage already includes the title, skip the title clip.

## Export

Use the saved `Insta_Export` preset.

Current preset:

* Format: MP4
* Codec: H.264
* Resolution: Timeline Resolution (1080 x 1920)
* Frame Rate: Timeline Frame Rate (30fps)
* Hardware Acceleration: Enabled
* Quality: Automatic
* Encoding Profile: Auto
* Key Frames: Automatic
* Frame Reordering: Enabled
