# SoundCloud Release Workflow

## Audio
- Upload final mastered WAV
- Confirm track title
- Artist: Syafka
- Genre: Techno
- Add relevant tags

## Artwork
Use the square Resolve artwork.

- Resolution: 3000 x 3000
- Format: JPEG
- Same artwork can also be used for Bandcamp

## Description
Keep descriptions short, philosophical and consistent with the track concept.

Example style:

There is no flood.  
No rising tide.  
No escape required.

Avoid long explanations of the track.

## Upload Check
Before publishing confirm:

- Mastered WAV uploaded
- Correct track title
- Correct artwork
- Description added
- Genre/tags added
- Visibility set correctly
- Download setting checked if required

## After Publishing
- Add track to Spotlight if appropriate
- Check artwork displays correctly
- Play part of the uploaded track to confirm audio is correct
- Copy/share link as required
